# KumRemote (คุมคอม)

ปุ่มสั่งคอมจากมือถือ: ปลุกคอม / Sleep / ปิดเครื่อง / เช็คสถานะ — ส่วนหนึ่งของ Arak Lab Tools

หน้านี้เป็นหน้าเว็บธรรมดา ไม่มีลิงก์ลับหรือรหัสอยู่ข้างใน ชื่อช่องสั่งงานถูกเก็บไว้ในมือถือของเจ้าของเท่านั้น

## ประวัติเวอร์ชัน
- 1.0 (26/11/2026) เวอร์ชันแรก: ปลุกคอม / Sleep / ปิดเครื่อง / เช็คสถานะ, เห็นผลตอบกลับในหน้าเดียว, ถามยืนยันก่อน Sleep และปิดเครื่อง, ติดตั้งเป็นไอคอนบนหน้าจอมือถือได้
- 1.1 (26/11/2026) ตั้งความสว่างจอของตัวปลุกได้: แถบเลื่อน 10–100% + สวิตช์ "หรี่เองเมื่อไม่มีคนแตะจอ" (ต้องใช้บอร์ด KumWake v1.8 ขึ้นไป)
